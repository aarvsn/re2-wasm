# tests/

End-to-end browser tests for re2-wasm.

Phase 1 ships only the unit-test suite (under each package's `_test.go`
files). End-to-end Playwright tests arrive in Phase 2 alongside the
asset-loading pipeline, because that is the first time the WASM module
has observable side-effects beyond "the canvas is pulsing".

## Planned layout (Phase 2+)

```
tests/
├── e2e/
│   ├── boot.spec.ts          # module loads, canvas pulses
│   ├── drop-file.spec.ts     # drag-and-drop mounts files
│   └── save-roundtrip.spec.ts # IndexedDB save + reload
├── fixtures/
│   └── synthetic/            # generated BIN/CUE stubs (never real RE2 data)
├── playwright.config.ts
└── README.md                 # this file
```

## Principles

* **Never ship real RE2 assets.** Test fixtures are synthetic byte
  sequences that mimic the file format headers; they are generated by
  helpers under `fixtures/synthetic/`, not checked in as binary blobs.
* **Run in CI.** Once Playwright is wired up, the CI workflow runs the
  e2e suite on Linux against Chromium, Firefox, and WebKit (Safari
  engine).
* **No external services.** Tests boot the local `make serve` server and
  drive it; they never reach the network.

## Running (Phase 2+)

```bash
make wasm
make serve &          # http://localhost:8080
cd tests
npx playwright install
npx playwright test
```
